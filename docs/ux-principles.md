# Principios UX/UI

1. El período siempre debe ser visible y fácil de cambiar.
2. La carga inicial pide solo fecha, descripción, grupo y monto.
3. Categoría, referencia, método y observaciones aparecen bajo “Más detalles”.
4. Los grupos históricos y las categorías nunca se confunden visual ni conceptualmente.
5. Los totales no validados se omiten y se explica por qué.
6. Los datos de demostración y estados no conectados se identifican de forma persistente.
7. Acciones críticas tienen confirmación y mensajes en español claro.
8. La tabla prioriza lectura, búsqueda y teclado sin replicar una cuadrícula de Excel.
9. La interfaz base usa Montserrat, superficies neutras, verde profundo y ámbar como acento funcional.
10. El diseño móvil conserva la tarea principal, aunque la carga intensiva se optimiza para escritorio.
